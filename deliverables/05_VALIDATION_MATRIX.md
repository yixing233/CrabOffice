# 05_VALIDATION_MATRIX — 验证矩阵与测试计划（CrabOffice v1.0 设计稿）

## 1. 三层验收定义（不可混用）
- **UI-PASS**：顶置标签栏在所有窗口可见、样式正确、交互正常、DPI/主题无误。
- **SWITCH-PASS**：UI-PASS + 标签切换/关闭/保存/打开同步全部正确。
- **SINGLE-WINDOW-PASS**：SWITCH-PASS + 仅一个主要可交互 Word 工作窗口：任务栏单条目、Alt+Tab 单条目、键盘焦点唯一、模态对话框正确、打印/保存/关闭正常。
- **UI-PASS 或 SWITCH-PASS 不构成 SINGLE-WINDOW-PASS。**
