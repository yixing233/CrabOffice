# 04_UI_SPEC — UI 规格：顶部标签栏与相关界面（CrabOffice v1.0 设计稿）

## 1. 总体布局
- 载体：CustomTaskPane（DockPosition=Top），内容为 WPF TabBarControl（经 ElementHost 承载）。
- 位置目标：Ribbon 下方、正文上方【官方 API 存在；实际相对位置/最小高度由 PoC-TP-1 实测确认，不得在确认前宣称"注入 Ribbon"】。
- 高度：默认 36 DIP（紧凑）/ 40 DIP（舒适）两档设置；禁止遮挡正文（正文区自动让位由 Word 窗格机制保证，实机确认）。
- 左区：固定标签分区（钉选）｜中区：常规标签横向滚动区｜右区：溢出按钮(▼)、搜索按钮(🔍)、"+"按钮。
- "+"按钮：左键=新建空白文档；长按/右键=菜单（新建/打开文件/打开工作区）。

## 2. 单个标签结构
[图标][标题][未保存点●][关闭×]；宽 160–220 DIP 自适应，>15 个标签进入滚动+溢出。
- 图标：按文件类型（docx/doc/只读锁/云文档）。
- 标题：Document.Name，过长省略号中段截断；同名文件在标题下以小字显示父目录（A10）。
- ×：仅悬停/激活态显示；固定标签以图钉替代 ×（A09）。

## 3. 状态矩阵
| 状态 | 视觉 | 触发 |
|---|---|---|
| Normal | 中性底色，常规字 | 非活动 |
| Hover | 浅高亮 | 指针悬停 |
| Active | 强调底色+底部 2px 强调条，字重 +1 | WindowActivate 回流确认后设置（不得先斩后奏） |
| Unsaved | 标题前 ●，主色 | Document.Saved=false 且非从未保存的只读；从 DocumentBeforeSave/WindowSelectionChange/节流轮询(≤500ms 有界)同步 |
| NeverSaved（未命名） | 标题=“文档N”，● 常显 | CanonicalPath 为空 |
| ReadOnly | 标题尾 🔒 | IsReadOnly |
| Pinned | 左区+图钉图标，无 × | 用户钉选 |
| DragOver | 插入指示竖线 | 拖拽排序中（A08） |
| Error | 标题红色感叹角标 | 关联操作失败（如另存失败） |
| Overflow | 溢出菜单列出全部标签（含搜索框） | 标签超可视宽度 |

## 4. 主题适配
- 跟随 Office 主题（彩色/深灰/白 + 深/浅色模式）：读取 Office UI Theme 注册表项【官方行为，需确认键位】+ 高对比度模式系统色。
- 验收：深浅两主题 + 高对比度下文字对比度 ≥ 4.5:1。

## 5. 键盘交互
| 键 | 行为 | 状态 |
|---|---|---|
| Ctrl+Tab / Ctrl+Shift+Tab | 按标签顺序前/后切换（A12，设置可关） | 【待实机验证】PoC-KB-1 |
| Ctrl+W | 关闭当前标签文档（若原生未占用则绑定） | 待验证冲突 |
| Alt+1..9 | 切换第 N 个标签（可选设置） | 经 KeyBindings/评估 |
| Tab 区聚焦时 ←/→ | 移动焦点标签，Enter 激活 | 辅助功能 |
| Esc | 关闭搜索/菜单浮层 | — |

不采用系统级全局键盘钩子作为默认方案（A12 红线）；仅当 Word 内绑定被证实不可行且用户明确同意时作为可选回退。

## 6. 异常与提示文案（规范）
| 场景 | 提示 | 行为 |
|---|---|---|
| 关闭未保存文档 | 交由 Word 原生保存对话框（不自制弹窗） | 取消→标签保留（A06） |
| 打开所在目录但文档未命名 | 菜单项禁用+tooltip“文档尚未保存到磁盘” | 无副作用（A11） |
| 工作区恢复时文件缺失 | “未找到：完整路径”列表 | 其余正常恢复（B02） |
| 收藏失效 | 图标置灰+tooltip 路径不存在 | 不自动删除（B05） |
| AI 服务不可达 | 面板内联错误，不阻塞标签操作 | 重试按钮（D 组） |
| 插件内部异常 | 右下角 toast“CrabOffice 遇到错误，已记录日志 #id” | 进入安全模式逻辑（A16） |

## 7. DPI 与多显示器（A15）
- 全程 PerMonitorV2 DPI 感知；跨屏拖动/缩放变更后 relayout；禁用位图缩放。
- 测试矩阵见 05 号文档；任何遮挡正文、错位、黑屏判 FAIL。

## 8. 无障碍
- 标签为 AutomationPeer 可枚举；名称=文档名+状态；支持键盘全操作；高对比度主题。
